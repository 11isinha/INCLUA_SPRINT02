
# 🔐 Critérios de Segurança e Proteção dos Dados — INCLUA

O INCLUA deverá utilizar critérios de segurança para garantir a proteção das informações pessoais dos usuários e a confiabilidade da plataforma.

## 1. Proteção dos Dados Pessoais
- Solicitar apenas informações necessárias para o funcionamento da plataforma.
- Não divulgar dados pessoais dos usuários sem autorização.
- Proteger informações como nome, e-mail e senha.

## 2. Segurança de Acesso
- Implementar cadastro e login de usuários.
- Utilizar autenticação para impedir acessos não autorizados.
- Permitir que cada usuário acesse apenas as informações e funcionalidades correspondentes à sua conta.

## 3. Proteção de Senhas
- Não armazenar senhas em texto aberto.
- Utilizar recursos seguros de autenticação e armazenamento de senhas.
- Garantir que as credenciais dos usuários sejam protegidas.

## 4. Segurança das Avaliações e Reclamações
- Proteger as informações enviadas pelos usuários sobre as academias.
- Evitar a exposição de dados pessoais em reclamações e denúncias.
- Permitir que os usuários registrem problemas relacionados à acessibilidade e à segurança dos equipamentos.

## 5. Proteção das Informações Armazenadas
- Utilizar um banco de dados com controle de acesso.
- Implementar regras para impedir consultas e alterações não autorizadas.
- Realizar cópias de segurança para evitar a perda de informações.

## 6. Conformidade com a LGPD
- Respeitar a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).
- Informar aos usuários como seus dados serão utilizados.
- Solicitar autorização quando necessário para a coleta e utilização de informações pessoais.

## 🎯 Objetivo

Garantir que o INCLUA seja uma plataforma segura, confiável e que respeite a privacidade dos usuários, protegendo suas informações durante a utilização do sistema.
